HIGDesign Design References

Local, renderable HTML references for the Apple-only HIGDesign SwiftUI design system.

Design Principles

  • Apple Human Interface Guidelines are the source of truth.
  • System colors, SF Pro text styles, and SF Symbols come first.
  • Components resolve visuals from tokens and themes, not hardcoded constants.
  • Support iOS, iPadOS, macOS, visionOS, tvOS, and watchOS with intentional platform adaptation.

Code Agent Workflow

  • Start from the HIG subpage that matches the component or modifier being changed.
  • Apply the HIGDesign interpretation and review questions on that page.
  • Verify the official Apple HIG page for final platform nuance.
  • Update the matching Requirements/*/REQ.md when behavior changes.
