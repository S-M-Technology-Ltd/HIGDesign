HIGDesign HIG/Foundations

Foundations

Privacy

Ask only for necessary access and explain user value in user-facing language.

HIGDesign interpretation

Never log private prompt text, reports, raw records, or secrets.

Must do

  • Use system-adaptive behavior for appearance, type, motion, and accessibility.
  • Document privacy and logging implications for UI that handles user text.
  • Do not create visual styling that fights platform defaults.

Avoid

  • Do not hard-code colors that fail light or dark mode.
  • Do not rely only on color for status.
  • Do not log sensitive text or raw platform objects.

  • redacted

HIGDesign review questions

  • Which HIGDesign workflow or surface uses this principle?
  • Does the implementation use native SwiftUI before custom UI?
  • Does it behave correctly on iOS, iPadOS, macOS, visionOS, tvOS, and watchOS where applicable?
  • Are empty, loading, error, disabled, and success states represented where needed?
  • Does the component avoid logging user-entered text, secrets, or private app content?
